|               | λ         | 0         | 1         |
| ------------- | ---------- | --------- | --------- |
| **q₀** | λ, L, q₁ |           |           |

| **q₃** | λ, S, q₃ | 0, L, q₂ | 1, L, q₂ |

Команды движения каретки: L — влево, R — вправо, N — отсутствие сдвига, S — стоп.

Определите число нулей на ленте после выполнения этой программы.
